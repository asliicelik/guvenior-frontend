
# 💜 Güvenior — AI-Powered Personal Finance Application

Güvenior is an AI-powered mobile financial coaching application developed as a Computer Engineering graduation project at Manisa Celal Bayar University.

The application is designed to help recent graduates and young professionals understand their spending habits, manage their income and expenses, and make more informed financial decisions.

Rather than focusing only on traditional budgeting, Güvenior combines personal finance management with behavioral insights, supportive AI-powered coaching, and financial goal simulations.

## 📱 About the Project

Güvenior aims to make personal finance management more accessible and approachable for young adults entering professional life.

Users can track their financial activity, review spending patterns, and explore how their current financial habits may affect future goals.

The application follows a supportive, non-judgmental approach to financial guidance.

## ✨ Key Features

- **User Authentication:** Login, registration, and password recovery interfaces.
- **Financial Dashboard:** Overview of income, expenses, and financial activity.
- **Income Management:** Record and review different sources of income.
- **Expense Tracking:** Manage expenses and organize spending by category.
- **Behavioral Insights:** View spending patterns and personalized financial observations.
- **Budget Management:** Monitor category-based spending limits.
- **Financial Goal Simulation:** Explore savings goals and future financial scenarios.
- **AI-Powered Coaching:** Receive supportive financial insights based on spending behavior.
- **Settings:** Manage application preferences and recurring expenses.

## 🏗️ Project Architecture

Güvenior follows a client-server architecture.

**Frontend:** Flutter and Dart provide the mobile user interface.

**Backend:** ASP.NET Core Web API handles business logic and financial operations.

**Database:** PostgreSQL stores user and financial data.

**AI Integration:** The OpenAI API supports personalized financial coaching based on aggregated behavioral data.

## 🚀 Getting Started

### Prerequisites

Before running the application, make sure you have:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android emulator or iOS simulator

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/asliicelik/guvenior-frontend.git
```

**2. Navigate to the Flutter project**

```bash
cd guvenior-frontend/guvenior
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

**Note:** Features that require live financial data, authentication, or AI coaching depend on the backend API and its configuration.
